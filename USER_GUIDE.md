# DMRS User Guide

## Getting Started

### 1. Account Creation
1. Open the DMRS application
2. Click "Register" tab
3. Enter your details:
   - Full Name
   - NEMSU Email Address
   - Password
   - Role (Faculty or Administrative Personnel)
4. Click "Create Account"

### 2. Logging In
1. Enter your email and password
2. Click "Sign In"
3. You'll be redirected to the Dashboard

## Using the Dashboard

The Dashboard shows:
- **Total Documents**: All documents in the system
- **Your Documents**: Documents you've uploaded
- **Public Documents**: Documents accessible to everyone
- **Recent Documents**: Latest documents added to the system

### Quick Actions
- Click "Advanced Search" to search documents
- Click "Chat Interface" for natural language queries
- Click "Upload Document" to add new documents

## Uploading Documents

1. Click "Upload" in the navigation bar
2. Fill in document information:
   - **Title**: Descriptive name for the document
   - **Document Type**: Select from dropdown (Memorandum, Policy, etc.)
   - **Access Level**: 
     - Public: Everyone can view
     - Restricted: Only you can view
3. Click the upload area to select a file (PDF, DOCX, or TXT)
4. Click "Upload Document"

### Supported Document Types
- **PDF Files**: Portable Document Format
- **DOCX Files**: Microsoft Word documents
- **TXT Files**: Plain text files

## Searching Documents

### Standard Search
1. Click "Search" in navigation
2. Choose a search mode:
   - **BM25**: Traditional keyword matching
   - **Semantic**: AI understands meaning
   - **Hybrid**: Best of both (recommended)
3. Enter your search query
4. Click "Search"

### Search Tips
- Use specific keywords for BM25
- Use natural phrases for Semantic search
- Hybrid mode works well for most queries

### Example Queries
- "faculty meeting minutes 2026"
- "leave application form"
- "memorandum about research"
- "BOR resolution regarding budget"

## Using Chat Interface

1. Click "Chat" in navigation
2. Type your question naturally, like:
   - "Show me all memoranda from 2025"
   - "Find documents about faculty development"
   - "What policies are related to research?"
3. Press Enter or click Send
4. View the response and recommended documents
5. Click any document card to view full content

### Chat Features
- Natural language understanding
- Conversational interface
- Document recommendations with relevance scores
- Chat history during session

## Viewing Documents

1. Click on any document from search results or dashboard
2. View document details:
   - Title
   - Document type
   - Access level
   - Upload date
   - Full text content
3. Use "Back" button to return to previous page

### Document Actions
- **Delete**: Available only for documents you uploaded
- Click "Delete" button and confirm

## Understanding Search Results

Each result shows:
- **Document Title**: Name of the document
- **Document Type**: Category (Memorandum, Policy, etc.)
- **Access Level**: Public or Restricted
- **Match Percentage**: How relevant to your query (higher is better)
- **Snippet**: Preview of matching content
- **Upload Date**: When document was added

### Match Scores
- 70-100%: Highly relevant
- 40-69%: Moderately relevant
- Below 40%: May not be shown

## Access Control

### Public Documents
- Visible to all users
- Can be searched by anyone
- Ideal for general university documents

### Restricted Documents
- Only visible to you (the uploader)
- Won't appear in other users' searches
- Use for drafts or personal documents

## Best Practices

### For Uploading
1. Use clear, descriptive titles
2. Choose appropriate document type
3. Set correct access level
4. Ensure document text is readable

### For Searching
1. Start with hybrid search mode
2. Use specific terms for better results
3. Try different phrasings if first search doesn't work
4. Use chat for complex queries

### Document Organization
1. Use consistent naming conventions
2. Include dates in titles when relevant
3. Select accurate document types
4. Review access levels regularly

## Troubleshooting

### Can't find a document?
- Try different search modes
- Use broader search terms
- Check if document is Restricted
- Verify document was uploaded successfully

### Upload fails?
- Check file format (must be PDF, DOCX, or TXT)
- Ensure file size is reasonable (< 10MB)
- Verify all required fields are filled
- Check internet connection

### Search returns no results?
- Try simpler search terms
- Switch to different search mode
- Use chat interface instead
- Check if you're logged in

## Tips for Power Users

### Effective Search Strategies
1. **Keyword Search (BM25)**: Use exact terms from document
2. **Semantic Search**: Describe what you're looking for
3. **Hybrid Search**: General purpose, works for most cases

### Document Management
- Upload documents regularly
- Use consistent naming
- Set appropriate access levels
- Delete outdated documents

### Using Chat Effectively
- Ask specific questions
- Include context in your query
- Review multiple results
- Refine queries based on results

## Keyboard Shortcuts

- **Enter**: Submit search/chat
- **Ctrl/Cmd + K**: Focus search bar
- **Esc**: Close dialogs
